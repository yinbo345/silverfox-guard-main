# 银狐防护主防程序（SilverFoxGuardSvc）

银狐防护的**系统级防线**：浏览器扩展管网页，主防程序管系统。这是一款独立的 Windows 主防程序——后台以 Windows 服务常驻（`SilverFoxGuardSvc.exe`），自带 WebView2 通知窗口、托盘式图形主界面，并经 Native Messaging 私有管道与[浏览器扩展](https://github.com/yinbo345/silverfox-guard)联动。

当前以 **v21 preview4** 形态发布，安装包可从[官网](https://silverfoxguard.dpdns.org/)下载。

## 它防什么

- **实时行为防护（八路事件源）**：进程创建 / 文件与注册表 / 网络外联 / 跨进程注入（ETW，Microsoft-Windows-Kernel-*）+ 进程资源监控 + 引导扇区防护 + 自启动项监视 + 勒索回滚——命中威胁先自动拦截，再在屏幕右下角弹出处理卡片（它在干什么 → 已自动拦截 → 是否撤销）；撤销即一键还原，误拦不伤文件；
- **勒索加密拦截**：截获混合加密的密钥落盘、识别批量加密改写，先回滚被加密文件再通知；配合快照机制，中招文件可自动恢复；
- **MBR 引导扇区防护**：安装时建立引导扇区基线，持续监视篡改，被改写即刻告警并可一键恢复；
- **系统主机进程注入检测**：探测 explorer / svchost / lsass 等系统进程里被注入的无签名恶意 DLL；
- **沙箱动态分析**：送检样本在隔离沙箱中运行，行为特征累计达阈值即判恶意；**沙箱没测出结论时处置权交回用户**（三按钮 + 30 秒倒计时，不选则自动删除并先留底到隔离区）；
- **定时扫描**：快扫约 3 分钟一轮、全盘 6 小时一轮、开机 2 分钟内完成首轮；
- **GPU 深度内容扫描**（可开关）：对用户可写目录的可执行/脚本文件批量匹配家族特征字节串，抓"名字正常但内容是银狐"的改名样本；
- **一键清除 / 高级清除**：普通清除失败自动升级高级清除——遏制（强杀进程树）→ 夺权（解 ACL）→ 硬删（POSIX 删除 + 重启登记）→ 连坐（清除同目录随机名衍生物）；每次清除写入「清除记录」。

## 关于本开源版本

本仓库是主防程序的**开源版本**。与官方发行版相比，**不含服务自保护逻辑**，包括：

- 定时自保复核（服务注册项检查 + 程序文件 ACL 加固）；
- 服务被删除后的自动重建；
- SCM 失败自动重启配置；
- **自身完整性校验的哈希基线比对**（官方版安装时把 EXE 哈希写入 `HKLM\SOFTWARE\SilverFoxGuard\ExeHash`，运行时比对；自行编译后哈希必然不同 ⇒ 每次扫描都误报"程序被篡改"。开源版已把该比对关闭，**仍保留签名指纹异常的日志记录**）；
- NM 宿主进程触发的服务自愈。

其余防护、检测、清除、回滚功能与官方发行版一致。

这样做的目的：防自保护对抗细节（重建服务、ACL 加固、完整性基线等手法）可能被恶意软件作者研究用于反制。如果你要自行构建并部署到生产环境，建议自行补上需要的自保护逻辑——相关代码以注释形式留在 `src/common.cpp`（`VerifySelfIntegrity`）与 `src/service.cpp`（`--install` 分支）里，取消注释即可恢复。

### 关于签名

**自编译版本没有代码签名证书是正常的，不影响任何功能。** 但要知道两件事：

1. 杀毒软件对**未签名程序**的误报率明显更高（缺少信誉积累）。本程序因为要做进程资源监控（周期性枚举全系统进程并读取 CPU 时间），这个行为形态与加密货币矿工的监控行为**在原理上无法区分**，因此在某些杀软（如卡巴斯基的行为检测）上可能收到误报。**这是形态相似导致的误报，不是恶意代码。** 处理办法是在杀软里把本程序加入信任区 / 受信任应用程序。
2. Windows 会在每次运行时提示"未知发布者"。

要消除这两点：自备代码签名证书（PFX + 密码文件）放在 `signing/` 目录下，`build.sh` 会自动检测并签名（主程序、shell 扩展、探针 DLL 都会签）。

### 云库验签（**不要删**）

`src/sfh_pubkey.h` 是**病毒库验签公钥**，公开发布是设计如此（公钥本来就要公开）。它的作用是让客户端只接受**官方签发**的病毒库，防止有人往恶意库里塞良性条目把杀软变成误报机器。

**私钥（`signing/sfh-signing.key`）绝不在本仓库内**，已被 `.gitignore` 挡住。请勿将私钥提交到任何公开仓库——拿到它就能伪造任意病毒库。

```
├── build.sh            # 构建脚本（MSVC，静态单文件 /MT）
├── data/
│   ├── probe_rules.txt     # 单文件查杀规则库（外置，可热更新）
│   ├── behavior_rules.txt  # 行为判定规则库（外置，可热更新）
│   └── rollback_rules.txt  # 回滚判定规则库（外置，可热更新）
└── src/
    ├── main.cpp            # 入口：命令行 / 服务模式 / NM 宿主模式
    ├── service.cpp/h       # SCM 服务控制 / 守护循环 / 命名管道 / 安装
    ├── scanner.cpp/h       # 扫描引擎：两态评分（正常/感染）+ 铁证直判
    ├── behavior.cpp/h      # 行为判定：八事件源归一化 + 评分 + 信誉
    ├── rollback.cpp/h      # 勒索回滚：密钥截获 / 双信号判定 / 快照恢复
    ├── bootguard.cpp/h     # MBR 引导扇区防护：基线 + 边沿监视 + 恢复
    ├── cleaner.cpp/h       # 一键清除 / 高级清除
    ├── matcher.cpp/h       # AC 自动机特征匹配
    ├── compute.cpp/h       # GPU 加速扫描（D3D11 批量字节串匹配）
    ├── mod_compat.cpp/h    # 跨版本兼容层（PEB 命令行读取等多策略）
    ├── mod_sfdb.cpp/h      # 哈希库（云库 + 本地库）
    ├── sandbox.cpp/h       # 沙箱动态分析 + 无结论决策（errhold）
    ├── probe.cpp/h         # 单文件查杀（右键菜单调起）
    ├── gui.cpp/h           # WebView2 通知窗口 + 右下角卡片
    ├── toast.cpp/h         # 告警卡片（深浅色主题）+ 决策卡
    ├── errhold.cpp/h       # 无结论文件的用户决策待决表
    ├── crashlog.cpp/h      # 崩溃留证（无条件装未捕获异常过滤器）
    ├── common.cpp/h        # 公共模块：JSON / 帧IO / SHA-256 / 管道
    └── shell/              # Win11 右键一级菜单（稀疏包 IExplorerCommand）
```

## 构建

1. 安装 MSVC BuildTools 2022 与 Windows SDK；
2. 从 nuget 下载 `microsoft.web.webview2 1.0.2651.64`，修改 `build.sh` 顶部 `WV2` 指向其解压目录；
3. 仓库根目录执行 `bash build.sh`，产物在 `dist/`。

程序本体为静态链接（/MT），无第三方运行库依赖；运行时规则在 `data/` 目录，可热更新。

构建脚本会自动跑三类自测（判据自测 / errhold 决策自测 / 决策卡渲染验收），任一不过即中止构建——这些都是踩过坑之后加的回归兜底。

## 隐私

主防程序不采集、不上传任何用户数据；与扩展的联动经命名管道完成，不开放任何网络端口。
